# Veya Marketing Analytics Case Study

## Digital Marketing Campaign Performance & ROI Optimization

> An end-to-end marketing analytics case study focused on evaluating digital campaign performance, customer conversion, and marketing ROI.

## About the Project

This project presents an end-to-end marketing analytics case study for Veya, a fictional Pakistani beauty and skincare e-commerce brand.

The purpose of this case study is to investigate how Veya's digital marketing campaigns perform across different channels, identify factors affecting customer conversion, and develop data-driven recommendations for improving marketing performance and return on investment.

The project follows a complete marketing analytics workflow:

**Ask → Prepare → Process → Analyze → Share → Act**

## Business Objective

The primary objective is to determine how Veya can use digital marketing data to:

- Evaluate campaign performance
- Understand customer conversion
- Measure marketing ROI
- Identify high-performing channels and campaigns
- Identify underperforming campaigns
- Improve marketing budget allocation
- Develop actionable marketing recommendations

## Tools & Technologies

- **Excel** — Data preparation and exploratory analysis
- **SQL** — Data analysis and marketing KPI calculations
- **Python** — Exploratory data analysis and visualization
- **Power BI** — Interactive marketing dashboard
- **GitHub** — Project documentation and portfolio

## Key Marketing KPIs

The analysis will evaluate:

- Impressions
- Clicks
- Click-Through Rate (CTR)
- Conversions
- Conversion Rate
- Advertising Spend
- Cost per Acquisition (CPA)
- Revenue
- Return on Advertising Spend (ROAS)
